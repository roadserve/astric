## 🎯 **Quick Setup (3 Steps)**

### **Step 1: Add a Customer**
```
/dashboard/billing/customers
→ Click "Add Customer"
→ Fill: Name, Email, Phone, GSTIN
→ Save
```

### **Step 2: Add Products**
```
/dashboard/billing/products
→ Click "Add Product"
→ Fill: Name, Price, Tax Rate
→ Save
```

### **Step 3: Create Invoice**
```
/dashboard/billing/invoices/create
→ Select Customer
→ Add Items
→ Save & Send
```

**Done! Your first invoice is created! 🎉**

## 🔥 **Common Tasks**

### **Create Sales Invoice:**
1. Go to `/dashboard/billing/invoices/create`
2. Select customer
3. Add items (from products or manual)
4. Review totals
5. Click "Save & Send"

### **Record Payment:**
1. Go to `/dashboard/billing/payments`
2. Click "Record Payment"
3. Select customer & invoice
4. Enter amount & method
5. Click "Record Payment"

### **Track Outstanding:**
1. Go to `/dashboard/billing/reports`
2. Select "Outstanding Report"
3. View receivables & payables

### **Create Subscription:**
1. Go to `/dashboard/billing/recurring`
2. Click "New Recurring Plan"
3. Set frequency & amount
4. Activate plan
